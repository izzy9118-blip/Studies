# Studies

Exploratory study repository for the Sanctum project.

## Purpose

This repository preserves close readings, exploratory analysis, provisional findings, objections, revisions, and possible future applications before any conclusion is considered for adoption elsewhere.

## Governing separation

- `Studies` preserves exploration and learning.
- Minister repositories preserve reconstruction specific to a minister.
- `Sanctum` receives only conclusions or structural changes later judged worthy of deliberate adoption.

No finding in this repository acquires Sanctum authority merely by being recorded here.

## Active studies

- `complex-analysis/` — Elias M. Stein and Rami Shakarchi, *Complex Analysis* (Princeton Lectures in Analysis II)

## Study discipline

Each study should preserve separately:

1. **Reading record** — what the source says, its order, argument, definitions, proofs, examples, and our joint understanding.
2. **Findings ledger** — provisional insights, hypotheses, objections, corrections, and possible applications.
3. **Application review** — only after the source has been sufficiently understood, a separate analysis of possible use in Sanctum or another repository.

Exploratory findings remain provisional until explicitly adopted through the governing process of the destination repository.
